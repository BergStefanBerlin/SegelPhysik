SegelPhysik V4 - P5c Schritt 1b: Ein-Objekt-Anzeige
===================================================
Stand: 12.10.2026

AEnderungen (nur demo_app.py):
1. Text oben rechts entfernt: Das Status-Prop wird initial LEER
   angelegt; alle Updates laufen ueber Slot 0 der Corner-Annotation
   (= unten links, der Kanal, der in der Sichtprobe funktioniert).
   Oben rechts bleibt dauerhaft leer.
2. Ein-Objekt-Regel: Immer genau EIN Objekt sichtbar. Space blaettert
   durch OBJEKTE (wrap-around): kegel -> quader -> pyramide -> boot.
   Neue Objekte: (name, typ)-Paar in OBJEKTE ergaenzen + Zweig in
   spawne() (typ=None bedeutet Boot).
3. Alle Objekte liegen in der Mitte des Wassers (0, 0, 0); das Boot
   auf MITTE + r_modell (wie bisher verschoben, nur zentriert).
4. Pausenfunktion entfernt: Space ist jetzt Objektwechsel. Die
   Tasten 1/2/3, 4 und 'a' (Mehrfach-Anzeige) sind weg - sie
   widersprechen der Ein-Objekt-Regel.
5. Unveraendert: r/s/z Modi (RUHEND friert die Szene ein), n Reset,
   +/- Tempo, F1-F4 Kamera, o SSAO, 5/6 Layer, q Ende.

Technik: Space kann ueber drei Kanaelle melden (Key-Event, Beobachter,
Poll); umschalten_objekt() ist auf 150 ms entprellt, so dass jede
physische Taste genau einmal zaehlt.
