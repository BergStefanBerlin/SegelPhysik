Fock-Anhebung (Schritt 4.2) - Durchdringung mit dem Rumpf beseitigt

PROBLEM
Die Fock (Dreieck tack/head/clew) tauchte mit beiden unteren Ecken in das
Rumpfvolumen ein (tack z_welt=0.1235 m und clew z_welt=0.3195 m, while das
Vordeck bis z_welt=0.4875 m aufragt). Zwei sich durchdringende Flaechen
-> Z-Fighting/Flackern, insbesondere mit SSAO.

LOESUNG (wie vom User praesziziert)
- head (obere Fixpunkt) unveraendert.
- tack und clew beide um dz = 0.38 m (Welt) bzw. du = 1.52 (Unity-Einheiten)
  nach oben verschoben -> Fock etwas kleiner.
- Danach liegt die gesamte Fock ueber dem hoechsten Rumpfpunkt
  (min z der Fock 0.5035 m > max z Rumpf 0.4875 m) -> keine Durchdringung
  mehr moeglich, Beweis durch lineare Interpolation (Minimum der z-Koordinate
  ueber einem Dreieck liegt an einer Ecke).

ZAHLEN
- Flaeche: 3.6315 -> 3.3379 m^2  (Masse bei fm=0.5 kg/m^2: 1.8157 -> 1.6689 kg)
- Bootsgesamtmasse aendert sich dadurch nur im vierten Nachkomma.
  DIE D-TESTS (test_tc_d1..d5) PRUEFEN HARTE REFERENZWERTE (z.B. 459.4368 kg)
  -> diese muessen nach dem Einbau einmalig neu generiert werden:

    python -c "import numpy as np; from segelphysik.core import boot_bau, massen; p,f = boot_bau.baue_boot(); k = massen.masse_koerper(p,f); print('Masse', k.masse); print('CM', k.schwerpunkt)"

  (Funktionsnamen ggf. an die eigene API anpassen - die Werte einfach in
  tests/test_koerper.py D-Block aktualisieren.)
